# Collaboration workflow

- Work on `feature/abdiaziz-development` for Abdiaziz's changes. Keep other developers' branches intact.
- Commit and push feature changes to `origin` (`git@github.com:ar-raxma-blg/alrahma_donation.git`).
- Open or update a pull request from the feature branch into `acceptance` for collaborative review.
- Leave pull requests unmerged. Do not enable auto-merge or push directly to `main` or `acceptance`.
- Report checks and the pull request link so the maintainers can review and merge.
